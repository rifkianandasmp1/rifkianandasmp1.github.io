Connect to GitHub

Your GitHub repository is the backend: publishing commits data/portfolio.json, and GitHub Pages redeploys the site in about a minute.

  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repository.
  3. Permissions → Repository → Contents: Read and write. Nothing else is needed.
  4. Generate, copy the token and paste it below.
